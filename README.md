# Jair Dev Landing

Landing page pessoal de desenvolvedor web com design moderno e animações fluidas.

## 🚀 Tecnologias

- Node.js (servidor estático)
- HTML5 / CSS3 (vanilla)
- JavaScript (vanilla)

## ✨ Features

- Design dark mode com gradientes e glassmorphism
- Animações suaves e efeitos de hover
- Cursor glow interativo
- Contador animado de estatísticas
- Código com efeito de digitação
- Totalmente responsivo
- Otimizado para SEO

## 🛠️ Como rodar

```bash
npm install
npm start
```

O site estará disponível em `http://localhost:3000`

## 📁 Estrutura

```
├── server.js          # Servidor Node.js
├── public/
│   ├── index.html     # Página principal
│   ├── styles.css     # Estilos
│   └── script.js      # Interatividade
└── package.json
```
